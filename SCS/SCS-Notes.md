## **Context files creation**
Use all the available documents under the folder "SCS-Input"  and created Project Context, Feature Context and Test Context under the folder "SCS-Context" as given below:

1.Create 'SCS_ProjectContext.md' by using the template @file:Project_Context.md 
2. Create 'SCS_FeatureContext.md' by using the teamplate @file:FeatureContext.md 
3. Create 'USCS_TestContext.md' by using the teamplate @file:TestingContext.md 

While creating the above context file, please make sure that @file:context_constraints.md  been cosidered
