# Test Cases - ADR-001: Messaging Abstraction Architecture
## IGNIS Adapter Integration Service - Transport-Agnostic Messaging

---

## Verified Facts

### Architecture
- Hexagonal Architecture (Ports and Adapters) pattern
- Three port interfaces: EventPublisherPort, EventSubscriberPort, EventReceiverPort
- All ports reside in domain module with no infrastructure dependencies
- Single messaging adapter per port with delegation to active transport

### Transport Modes
- In-memory transport using Vert.x EventBus (standalone mode)
- Kafka transport (distributed mode)
- Transport selected via configuration: adapter.transport=in-memory|kafka
- Only one transport active at runtime
- Switching requires configuration change only (no code changes)

### Core Modules
- Receiver: Event ingestion and validation
- Handler: Business logic processing and transformation
- Dispatcher: Event routing and publishing
- Modules can be enabled/disabled via configuration

### Configuration Properties
- adapter.transport: Transport mode selection
- adapter.receiver.enabled: Enable/disable Receiver (default: true)
- adapter.handler.enabled: Enable/disable Handler (default: true)
- adapter.dispatcher.enabled: Enable/disable Dispatcher (default: true)

### Dispatch Centers
- IPL: events-ipl topic
- WDX: events-wdx topic
- UCRI: events-ucri topic
- POLICE: events-police topic
- Per-center configuration: enabled, topic, url, retry-attempts, retry-delay-ms, timeout-ms, ssl-enabled, cert-path, key-path, dlq-topic

### Message Envelope
- Immutable once created
- Contains metadata and payload
- correlationId and headers for observability
- Serializable without transport-specific dependencies

### Cross-Cutting Concerns
- Logging: logs publish/receive operations
- Retry: configurable attempts and backoff
- Metrics: publish/receive/failure counts and latency
- Implemented via port decorators in infrastructure layer

### Event Types
- CreateRequest: IPL → WDX/UCRI/POLICE
- AcceptOperation: WDX/UCRI/POLICE → IPL
- RejectOperation: WDX/UCRI/POLICE → IPL

### Constraints
- Event ordering preserved based on partition key
- Events must be acknowledged within 10 seconds
- Architecture guardrails enforced via build failure on violation
- Invalid/missing transport config fails startup with descriptive error

- Specific metric names and formats
