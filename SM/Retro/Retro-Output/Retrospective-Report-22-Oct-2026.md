# To improve

## Avoid UAT Refreshes During Dependent Story Development

When the team is working on dependent stories, such as the Relevant Deal related work, UAT refreshes should be avoided until the release is completed. Performing refreshes during active development can create data and environment discrepancies that impact testing and delivery confidence.

**– 1 Members contributed this point**

## Strengthen Post-Refresh and Post-Deployment Verification

After environment refreshes, translations and other configurations can go missing in UAT. The team should assign 1–2 dedicated owners to verify the environment post-refresh, document missing items, and report them for correction. Additionally, post-deployment checks should be improved to ensure nothing is missed, including translations, permission set access, and other required configurations, with all post-deployment steps kept in mind whenever a UAT refresh happens.

**– 3 Members contributed this point**
