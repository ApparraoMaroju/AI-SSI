# PRIMARY OBJECTIVE

Before creating any slides, clearly identify:

1. What should the audience KNOW after this presentation?
2. What should the audience FEEL after this presentation?
3. What should the audience DO after this presentation?

Every slide must directly support these objectives.

If any slide does not contribute to the objective, revise or remove it.

---

# UNDERSTAND THE AUDIENCE

Tailor the presentation according to the audience by considering:

- Existing knowledge level
- Professional background
- Interests
- Business concerns
- Decision-making authority
- Technical understanding
- Expected outcomes

Use language, examples, and visuals appropriate for the audience.

Avoid unnecessary technical jargon unless presenting to experts.

---

# PRESENTATION STRUCTURE

Create a logical, story-driven presentation using the following flow:

1. Cover Slide
2. Agenda
3. Introduction / Background
4. Current Situation
5. Problem Statement
6. Analysis
7. Supporting Evidence
8. Key Insights
9. Proposed Solution
10. Benefits
11. Implementation Plan
12. Risks & Mitigation
13. Recommendations
14. Key Takeaways
15. Conclusion
16. Thank You

Modify sections only if necessary while maintaining a clear storytelling flow.

---

# CONTENT WRITING STYLE

The presentation content must:

- Sound naturally written by a human
- Be concise and impactful
- Use professional business language
- Avoid repetitive AI-generated phrases
- Be presenter-friendly
- Use strong, action-oriented headings
- Be easy to speak aloud

Avoid:

- Long paragraphs
- Robotic wording
- Generic corporate clichés
- Repeated sentence structures
- Excessive technical language

# SLIDE CONTENT RULES

Each slide should include:

- One primary message
- Three to six concise bullet points
- Short keywords instead of long text
- Minimal reading
- Clear visual hierarchy

Use the 6×6 rule as a guideline, not a strict requirement.

Slides should reinforce the presenter—not replace the presenter.
