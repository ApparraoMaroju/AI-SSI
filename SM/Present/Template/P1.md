# PRIMARY OBJECTIVE

Before creating slides, clearly define:

1. What should the audience KNOW?
2. What should the audience FEEL?
3. What should the audience DO after the presentation?

Ensure every slide contributes directly to these objectives.

# PRESENTATION STRUCTURE

Create the presentation using the following structure.

1. Cover Slide
2. Agenda
3. Background / Context
4. Problem Statement
5. Why It Matters
6. Current Situation
7. Supporting Research
8. Data Analysis
9. Key Insights
10. Proposed Solution
11. Benefits
12. Implementation Roadmap
13. Risks & Mitigation
14. Case Study / Real Example
15. Recommendations
16. Future Opportunities
17. Key Takeaways
18. Conclusion
19. Questions & Answers
20. Thank You / Contact

Adjust sections based on presentation purpose while maintaining a logical story.

# CONTENT WRITING STYLE

Write exactly like an experienced consultant.

The writing should feel:

✓ Human

✓ Natural

✓ Confident

✓ Professional

✓ Easy to speak aloud

Avoid:

❌ AI-style wording

❌ Generic corporate clichés

❌ Repetitive phrases

❌ Robotic formatting

❌ Overly academic language

Use:

• Powerful headlines
• Clear subheadings
• Short paragraphs
• Concise bullets
• Strong action verbs
• Smooth transitions

Slides should support the presenter rather than replace them.

---

# SLIDE CONTENT RULES

Each slide should contain:

• One core message
• 3–6 concise bullet points
• Keywords instead of paragraphs
• Strong visual hierarchy
• Minimal text
• Presenter-friendly wording

Use the 6×6 guideline as a recommendation, not a strict rule.
