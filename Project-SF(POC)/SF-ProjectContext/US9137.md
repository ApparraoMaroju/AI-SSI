**BLM-9137 Improve Add and Edit Area Offerings Flow Usability**
**Description**
I as ...	Opportunity Owner / Bid Manager
want...	clearer buttons, improved navigation and better‑sized windows in the Add and Edit Area Offerings flows
so/that...	I can work more intuitively, avoid mistakes and manage Area Offerings more efficiently.
Additional Information:

The Add Area Offerings and Edit Area Offerings flows implemented under SFSUPPORTDE_BLM-6057 require several usability enhancements to align the user experience with common navigation and interaction patterns.

In the "Add Area Offerings" flow the first dialog must be updated so that the "Cancel" button is positioned on the left side of the screen making the action easier to recognize and consistent with standard UI conventions.



In the second dialog of the Add flow the buttons "Cancel" and "Back" must switch positions and "Back" must be renamed to "Previous".



The Edit Area Offerings flow requires additional refinements. In the first dialog, the window must dynamically adjust its height based on the number of existing Area Offerings to reduce unnecessary grey space. In the same screen, the button "Save" must be renamed to "Save & Close" / "Speichern & Schließen" and the button "Add Area Offerings" must be renamed to "Save & Add Area Offerings" / "Speichern & Area Offerings hinzufügen"



When a user clicks "Save & Add Area Offerings" the system must not only apply removals but also persist any changes the user made to Amount, Quantity, etc..

In the second screen of the Edit flow, an "X" icon must be added in the upper right corner to allow users to close the dialog at any time. Additionally, the "Cancel" button must be moved to the left.



In the third and final screen of the Edit flow, the window must also dynamically adjust to the number of selected Area Offerings. An "X" icon must be added in the upper right corner. The button "Back" must be renamed to "Previous" and "Previous" must switch places with "Cancel" placing "Cancel" directly next to the "Save" button for improved clarity and workflow consistency.



Remark: Only the translations explicitly mentioned above are changed; all other translations remain as they are today.

**Acceptance Criteria**
-The "Cancel" button is positioned on the left side in the first screen of the Add Area Offerings flow.
- The buttons "Back" and "Cancel" have swapped positions in the second screen of the Add Area Offerings flow.
- The button "Back" is renamed to "Previous" in the second screen of the Add Area Offerings flow.
- The window in the first screen of the Edit Area Offerings flow dynamically adjusts to the number of existing Area Offerings.
- The button "Save" is renamed to "Save & Close" in English and "Speichern & Schließen" in German in the first screen of the Edit Area Offerings flow.
- The button "Add Area Offerings" is renamed to "Save & Add Area Offerings" in English and "Speichern & Area Offerings hinzufügen" in German in the first screen of the Edit Area Offerings flow.
- Clicking "Save & Add Area Offerings" saves all modifications to existing Area Offerings, including deletions and updates to Amount and Quantity.
- An "X" close icon is displayed in the upper right corner of the second screen of the Edit Area Offerings flow.
- The "Cancel" button is positioned on the left side in the second screen of the Edit Area Offerings flow.
- An "X" close icon is displayed in the upper right corner of the third screen of the Edit Area Offerings flow.
- The window in the third screen of the Edit Area Offerings flow dynamically adjusts based on the number of selected Area Offerings.
- The "Back" button is renamed to "Previous" in the third screen of the Edit Area Offerings flow.
- The buttons "Previous" and "Cancel" switch positions in the third screen, placing "Cancel" directly next to "Save".
- Only the translations explicitly mentioned are updated; all other translations remain unchanged.
