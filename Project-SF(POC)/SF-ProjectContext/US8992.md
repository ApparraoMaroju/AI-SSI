# US8992 - Streamlining Compte Statistics Logic in Opportunity Automation (Salesforce2Compte)

## User Story

**I as...** an Area Controlling employee

**want...** the Compte Statistics on Opportunities to be derived using a simplified and FiCo aligned logic based on two input parameters only

**so/that...** the resulting values are accurate, consistent and fully compliant with the new requirements of the Group Controlling.

---

## Additional Information

With this User Story we redesign and streamline the existing automation that populates Compte Statistics fields on Opportunities and later in Contracts, ensuring adherence to the updated specifications defined by Group Controlling and FiCo. The current automation contains numerous outdated logic paths that are no longer relevant.

To align with the revised reporting requirements, only four output parameters will remain in use:
- **Activity Compte**
- **Service Type Compte**
- **Commitment Type Compte**
- **Contract Type Compte**

These outputs will be generated exclusively from the two input parameters:
- **Business Type for Compte Statistics** (introduced as part of SFSUPPORTDE_BLM 8970)
- **(Expected) Contract Type**

All valid combinations and their respective outputs are defined in the Mapping sheet of the provided Excel file: `20260320_TranslationLogicsCompteSFDC_Salesforce@SopraSteria_v5.0.xlsx`

These specifications must be implemented exactly as documented. All legacy combinations that do not appear in the mapping must be removed from the automation. This reduction ensures transparency, consistent statistical classification, and reliable data quality aligned with the expectations of Group Controlling and Area Controlling.

### Field Relabeling

As part of this change, the remaining Compte fields will be relabeled to ensure consistency. Fields not displayed on page layouts will no longer include the "Hidden" suffix, aligning the naming with established conventions for both functional and technical fields and improving clarity for all users interacting with the data model.

| Old Field Name | New Field Name |
|----------------|----------------|
| Activity Compte Hidden | Activity Compte |
| Commitment Type Compte Hidden | Commitment Type Compte |
| Service Type Compte Hidden | Service Type Compte |
| Vertragsart Compte Hidden | Contract Type Compte |

**PO Folder:** BLM-8997_UpdateSalesforce2Compte

---

## Solution Design

1. **Rename the mentioned four fields on Opportunity object.**

2. **Update logic in "Update Compte Statistics on Contract Record"** - the logic should be to update only the mentioned four fields and other logic should be removed.

3. **Update logic for flow "Translation Salesforce Compte Statistics"** - to populate data on four compte statistics fields on Opportunity on basis of mapping provided in the sheet, logic will be updated so that the fields on Opp get updated on basis of "Business Type for Compte Statistics" and "Expected Contract Type" field.

---

## Acceptance Criteria

- [ ] The four Compte Statistics output fields are populated correctly based on the two input parameters Business Type for Compte Statistics and (Expected) Contract Type, using only the logic combinations defined in the Mapping sheet of the referenced Excel file (20260320_TranslationLogicsCompteSFDC_Salesforce@SopraSteria_v5.0).

- [ ] All logic combinations that are not included in the Mapping table of the referenced Excel file have been fully removed from the automation.

- [ ] All combinations documented in the Mapping table have been implemented exactly as specified and produce the expected output values.

- [ ] Only the four required Compte Statistics output fields remain active in the automation and no deprecated fields or logic paths persist.

- [ ] The remaining Compte fields have been renamed consistently and no longer include unnecessary suffixes such as "Hidden":
  - Activity Compte Hidden → Activity Compte
  - Commitment Type Compte Hidden → Commitment Type Compte
  - Service Type Compte Hidden → Service Type Compte
  - Vertragsart Compte Hidden → Contract Type Compte

- [ ] When creating or updating an Opportunity, or when a Contract is generated, the correct Compte Statistics values are written according to the newly defined logic – as it is today.

- [ ] A sub-task for the required migration has been created.
