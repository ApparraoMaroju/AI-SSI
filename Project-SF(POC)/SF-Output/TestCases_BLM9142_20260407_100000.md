# Test Cases - BLM-9142: Opt-Out Management Standardization
## User Story: Groundwork for Standardization and Optimization of Opt-Out Management Across Contacts and Leads

---

## Verified Facts
- Section "Opt Out Overview" renamed to "Contact Restrictions" (EN) / "Kontaktbeschränkungen" (DE)
- Field "HasOptedOutOfEmail" relabeled to "Do Not Email" (EN) / "Nicht per E‑Mail kontaktieren" (DE)
- Selecting "Do Not Email" triggers "Total Opt Out" in Account Engagement
- Removing "Do Not Email" checkmark does NOT update Total Opt Out field
- Help text for "Do Not Email" field defined (bilingual)
- "Print Opt Out" field removed from section
- "Print Opt Out" marked with _zdelete for deletion
- "Do Not Call" German label updated to "Nicht per Telefon kontaktieren"
- Help text for "Do Not Call" field defined (bilingual)
- "Newsletter Opt Out" removed from "Contact Restrictions"
- "Newsletter Opt Out" displayed only under "Marketing Information" tab
- "Reason for Opt Out" field removed from page layout and prepared for deletion
- New field "Objection Details (Email)" / "Details Widerspruch (E‑Mail)" created
- New field "Objection Details (Phone)" / "Details Widerspruch (Telefon)" created
- Contact Restrictions section uses two-column layout
- Migration logic: If "Reason for Opt Out" has text and HasOptedOutOfEmail=true → migrate to "Objection Details (Email)"
- Migration logic: If "Reason for Opt Out" has text and DoNotCall=true → migrate to "Objection Details (Phone)"
- Migration logic: If both checkboxes true → text migrates to both fields
- Tab "Marketing" renamed to "Marketing Information"
- "Latest Publication" field removed from Account Engagement Information
- "Newsletter Opt Out" relabeled to "Marketing Opt‑Out" (EN) / "Marketing‑Opt‑Out" (DE)
- Help texts added for: Account Engagement Score, Account Engagement Last Activity, Account Engagement Comments, Marketing Opt‑Out, Account Engagement Hard Bounced
- All fields in "Account Engagement Information" section are read-only
- Account Engagement Information layout: Left column (Score, Last Activity, Comments), Right column (Marketing Opt‑Out, Hard Bounced)
- All changes apply equally to both Lead and Contact records

---

## Missing / Unknown Information
- Exact error messages when attempting to edit read-only fields
- Specific UI behavior when help text icon is clicked/hovered
- Validation rules for new fields (character limits, allowed characters)
- Behavior when language setting switches between EN/DE
- Exact timing/mechanism of Total Opt Out sync with Account Engagement
- Migration script execution details (batch size, error handling)
- Specific field API names for new fields
- User permission requirements for viewing/editing fields
