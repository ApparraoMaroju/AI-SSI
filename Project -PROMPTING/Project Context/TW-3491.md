# Feature Context: Processing Status Tile (Bearbeitungsstatus)

## Overview
A new tile named "Processing status" (Bearbeitungsstatus) is added to the dashboard to provide users with an overview of all actions currently being processed. When the tile is activated, a pop-up displays detailed information about these actions and allows navigation to continue the release process.

## User Stories
- As a user, I want to see a "Processing status" tile on the dashboard so that I can have an overview of all actions currently being processed.
- As a user, I want to open the "Processing status" tile so that I can view details of actions being processed.
- As a user, I want to select an area in the pop-up so that I can navigate to the original mask and continue the release process.

## Acceptance Criteria
- [ ] A new tile named "Processing status" is added to the dashboard.
- [ ] The tile displays statuses of actions: saved, for approval, and approved.
- [ ] When the tile is activated, a pop-up appears showing current actions being processed.
- [ ] Users can select an area in the pop-up to navigate to the original mask for continuing the release process.
- [ ] Performance considerations are addressed, potentially using a separate backend endpoint for efficient data handling.
